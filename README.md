# ML-FIAP-TC1 - Pipeline Preditivo de Churn

Tech Challenge da Fase 1 da Pós Tech em Machine Learning Engineering (FIAP, turma 12MLET).

Uma operadora de telecomunicações está perdendo clientes. O objetivo é construir, da análise exploratória ao modelo servido via API, um classificador de propensão a churn usando o ecossistema Scikit-Learn e expô-lo com FastAPI.
